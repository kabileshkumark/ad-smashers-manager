# Version 1.0 - Technical Build 1.0.26

## Payment Reminders

- Omit the Contributions section and its total when there are no contributions for the reminder period.
- Combine an activity payer's own settled share and derived Credit into one Activity payment contribution for that activity and payer. For example, a 20 AED own share plus 40 AED Credit displays as a single 60 AED contribution. The 20 AED share remains in usage.
- Group entries by activity ID and payer ID, preserving separate activities with the same name and separate payers. Existing period selection and recipient scoping remain in place.
- Contribution totals, usage totals, dues, remaining Credit/Advance and recorded financial data are unchanged. This is a message-formatting change only.
