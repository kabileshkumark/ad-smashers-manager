# Version 1.0 - Technical Build 1.0.20

Owner approved the local court-number QA candidate for production on 1 October 2026.

## Changes

- Add Court Numbers to each session booking row, for example `2, 4` for a two-court booking. Enter numbers for all rows together, or leave them blank for the existing unnumbered workflow.
- Reject mismatched counts, invalid numbers, duplicates, and overlapping bookings of the same physical court. Adjacent and overnight reuse remains valid.
- Session cards, Courts view and the published final list use the recorded numbers and time breakdown. Example: courts 2, 4 and 6 from 7-8 PM; courts 2 and 4 from 8-9 PM.
- Preserve original booking rows, manual capacity, recurring-session independence and existing roster ordering. A court available for only part of the session shows its available time. When the changing court set has no single fixed mapping, show Player Groups alongside the explicit schedule rather than inventing a court assignment.
- Court numbers are descriptive metadata. Number-only edits do not alter fees, player charges, balances, ownership, capacity, or financial-basis guards. Poll copy and legacy final-list content remain unchanged.
