# Version 1.0 - Technical Build 1.0.13

Owner-approved attendance correction release, 6 September 2026.

## Changes

- Attendance and guest edits no longer require clearing automatically derived Advance or Credit.
- Revised charges recalculate through the existing ledger without rewriting receipts or transferring ownership of funds.
- A removed attendee who was present in both the poll and manual attendance stays removed after refresh and export/import.
- Removing an attendance-only player preserves automatic poll syncing.
- Specific deletion warnings remain visible, with the previous view preserved. Missing targets still receive a fallback error.
- Recorded session payments and active cash allocations continue to require reversal before destructive attendance edits. Retained history still prevents hard session deletion.

## Verification

- 161 automated regression tests pass.
- Production build and version synchronization pass.
- Owner-approved local QA covered attendance removal, guest charge recalculation, reload persistence, derived coverage, and recorded-payment protection.
- Private exports and the isolated QA harness are excluded from Git and Hosting.

## Release Boundary

Deploy Firebase Hosting only. No database schema, rules, indexes, functions, or data migration is included. The technical build changes to 1.0.13; the formal release remains Version 1.0.

Rollback source: `v1.0.12`. Rebuild that tag and redeploy Hosting. A Hosting rollback does not undo later user data edits; attendance corrections use the existing data schema.
